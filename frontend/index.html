ESP32 DevKit V1 Pin Configuration

The 4-channel relay module is optically isolated. Only safe general-purpose output pins are assigned to avoid conflict with strapping pins and SPI flash.

Relay Channel ESP32 GPIO Appliance Controlled Relay Trigger Logic
Relay 1 (IN1) GPIO 26 Living Room Light Active-LOW (0V = ON)
Relay 2 (IN2) GPIO 25 Bedroom Light Active-LOW (0V = ON)
Relay 3 (IN3) GPIO 33 Living Room Fan Active-LOW (0V = ON)
Relay 4 (IN4) GPIO 32 Bedroom Fan Active-LOW (0V = ON)
Safety Notice: Pins 6 to 11 are permanently connected to the onboard SPI flash and must never be configured. Pins 34 to 39 are input-only.
ESP32 Hardware Simulator (Mock Node)

Evaluate and demonstrate the entire system immediately on Windows without waiting for physical hardware wiring!

# Run the digital twin in PowerShell / Command Prompt:
cd iot-home-automation
python simulator/mock_esp32.py

The simulator sends realistic Wi-Fi telemetry heartbeats, polls pending commands every 1.2s, flips virtual relays with millisecond delay, and returns cryptographic token-authenticated acknowledgements!

High Voltage Electrical Safety Protocol

For academic demonstration and laboratory testing, low-voltage DC demonstration loads (5V/12V LEDs and DC fans) are strongly recommended. If connecting 230V AC mains loads, an enclosed DIN-rail mounted relay enclosure, fuse protection, and inspection by a certified electrician are mandatory.
